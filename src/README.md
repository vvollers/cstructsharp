# Product source

`CStructSharp/` is the .NET 8/.NET 10 library. `CStructSharp.Core/` is not a project but the sources both the library and the generator compile: the layout parser, expressions, compiled model and placement, codec descriptors, diagnostics texts, introspection, and options - everything known before a byte is read (its README lists the rules). `CStructSharp.Generators/` is the `[CStructLayout]`/`[CStructMapped]` source generator and the `CSG` analyzer (`netstandard2.0`, Roslyn 4.8), packed into the library's NuGet package under `analyzers/dotnet/cs` with `build/CStructSharp.props`/`.targets`; it is never referenced as an assembly. `CStructSharp.Wasm/` is the managed WebAssembly bridge (exports, DTOs, JSON projection); the JavaScript adapter, declarations, and bundle pieces live in `packages/cstructsharp/`.
