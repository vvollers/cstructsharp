# npm package inputs

`cstructsharp/` contains authored Node/browser loaders, the Vite integration, copy command, package metadata, README, and Pidgin license. It is a private staging template, not a complete installable package. Run `npm run pack:npm` then `npm run test:npm` from `apps/workshop/` after publishing WASM. The actual tarball, runtime, types, and notices are assembled under ignored `artifacts/npm/`.
