# Work with stored pointers

A stored pointer is a number in the data that gives the position of another value in the same file or message; it is
never a process memory address. [Pointers and addressing](../language/pointers-and-addressing.md) is the one page that
explains them: how to declare one, follow it with a runnable example, choose absolute or relative coordinates, read a
counted target, select pointer levels in a path, and set the read limits.

For unsigned virtual addresses in mapped memory images, use [Analyze mapped memory](memory-analysis.md) instead.
