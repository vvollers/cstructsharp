# Test and lesson explorer

`src/` contains the Vue application and curated lessons. `scripts/generate-test-demos.mjs` extracts documented managed tests from `tests/CStructSharpTests/`; `src/generated/test-demos.json` is ignored output. The WASM boundary and its types come from `apps/shared`. `tests/` covers browser behavior and generated C#; the package's own browser and type tests live in `packages/cstructsharp/tests`. Install dependencies with `npm ci` at the repository root (the npm workspace), then run `npm run build`, `npm run test:unit`, and `npm run test:e2e` here. `npm run build` stages the WASM publication (run `npm run build:wasm` at the repository root first), builds `dist/`, and checks that `dist/` embeds exactly that publication; `npm run build:frontend` assumes staging already exists. Run `npm run test:demos` to verify extraction, and `npm run refresh:catalog` after adding or renaming managed tests so `tests/catalog-baseline.json` describes the new catalog. Package commands call repository-owned tooling under `tools/`.
