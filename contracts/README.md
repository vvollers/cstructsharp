# Reviewed contracts and fixtures

API snapshots, language examples, compiler facts, performance budgets, and documentation policies are authoritative reviewed inputs, not disposable build output. Managed tests and tools read them; DocFX publishes JSON/TXT under `/docs/contracts/`. `published-files.json` enumerates required published inputs. Update it when deliberately adding or removing a contract. Preserve historical API baseline IDs when moving files. See [testing](../docs/project/testing.md) for validation commands.
